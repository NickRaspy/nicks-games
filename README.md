# Игры Ника · Nick's Games

Хаб игр в сообщении Telegram. Интерфейс берёт язык клиента, а перед началом Wordle игрок выбирает русский или английский словарь. Чтобы вернуться к выбору языка, нажми «Назад» и подтверди выход. Доска очистится, и следующая игра начнётся с другого слова.

Нужно угадать слово из пяти букв за шесть попыток. Зелёный цвет означает букву на своём месте, жёлтый — букву на другой позиции, серый — отсутствие подходящего вхождения. В русской игре вместо Ё используется Е.

Прогресс сохраняется на устройстве отдельно для каждого языка и сообщения. При первом запуске Wordle бот скачивает выбранный [словарь](data/README.md) и кэширует его в памяти на 24 часа. На Vercel кэш общий только для запросов в одном тёплом экземпляре функции. При недоступном источнике русский язык использует резервный OpenCorpora, а английский может использовать ранее загруженный кэш.

`wordle.html` можно открыть прямо в браузере из папки проекта. Тогда словарь скачивает браузер. В Telegram загрузку и проверку догадок выполняет бот.

## Запуск на компьютере

Нужен Node.js 22.19 или новее в ветке 22. Добавь `TELEGRAM_BOT_TOKEN` в `.env`, затем запусти:

```powershell
npm start
```

Отправь `/start` или `/wordle` в личном чате с ботом. Каждая команда создаёт новое сообщение с хабом. Для локального запуска у бота должен быть отключён вебхук. Если у тебя уже есть `.env` с токеном, можно использовать его.

## Vercel

1. Импортируй проект в Vercel и добавь в его Production Environment Variables `TELEGRAM_BOT_TOKEN` и отдельный `TELEGRAM_WEBHOOK_SECRET` (случайная строка из букв латиницы, цифр, `_` и `-`).
2. После деплоя добавь тот же секрет в локальный `.env`. Зарегистрируй публичный адрес функции:

   ```powershell
   npm run webhook -- https://<проект>.vercel.app/api/telegram
   ```

3. Отправь `/start` в личном чате с ботом.

База данных не нужна. Бот отправляет HTML через `sendWidget`, а Telegram выполняет игру внутри сообщения. Для уже настроенного вебхука повтори команду регистрации, чтобы добавить обновления `widget_query`. Открой новый виджет командой `/wordle`, чтобы получить актуальную версию игры.
